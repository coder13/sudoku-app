# Sudoku component catalog

Browse the same React components and copy used in the app.

- **Design system → Buttons → Usage** shows which button to choose, with live examples of each state.
- **Small** — hint cards, breadcrumbs, diagram links, theme swatches, and update prompts.
- **Medium** — grids, input controls, puzzle dialogs, settings sections, and lesson exercises.
- **Large** — the play workspace, completion flow, and Learn pages.

For copy review, open **Small → Hints → Copy review** to compare all techniques and fallback messages in one place. The difficulty folders contain a searchable story for each technique. The examples come from the Sudoku engine, and the app formats the copy.

Use **Appearance** to switch between light and dark, and **Viewport** to check narrow layouts. Full workspace stories use an isolated in-memory puzzle library, so you can play and change settings without touching your saved puzzles.
