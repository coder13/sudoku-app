# Pattern tools in Play

Open **Subsets** from the puzzle menu or the mobile input tools. The panel uses one row, column, or box at a time.

- In **Hidden**, select digits to compare their locations.
- In **Naked**, select cells to see the digits they contain.
- **Find a subset** searches the selected house on request. Use **Show pattern** and **Show removals** to reveal the analysis in steps.

Open **Chains** and select **Show strong links**. The overlay marks every strong link between highlighted candidates. This includes links within two-candidate cells if both digits are highlighted. Select a link endpoint to start a sketch. All links use the same style, and the overlay reads the current candidate graph.
