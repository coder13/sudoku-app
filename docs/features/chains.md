# Edit a chain branch

Press **X** to open **Chains** and start drawing. Press **X** again to stop drawing. You can also open **Chains** from **Puzzle options**.
Reloading the same browser tab restores the open Chains panel and its drawing mode.

1. In **Draw links** mode, select **End path** to clear the current selection.
2. Select a candidate with one link in the active chain.
3. Select the same candidate again to remove that link.

**Undo edit** restores the link. The candidate stays on the grid.
After undoing an added link in Draw links mode, click another candidate to branch from the restored endpoint.

Open the three-dot **Chain actions** menu and select **Choose colors** to change the active chain’s color pair. The timer pauses while the chooser is open. Select **Edit color pairs** to change the presets in Settings.

The notation shows branches as paths separated by commas. A candidate at a branch junction appears in each path that joins there.

Drawing a link between two chains joins them under the earlier chain number and its color pair. Use **Undo edit** to separate them again.

Candidates connected by strong links alternate two colors. Each connected drawing uses one pair, including when weak links join its branches. Disconnected drawings cycle through five pairs. Weak links are gray and dashed. Candidates without a strong-link color are gray, including candidates in a loop that cannot alternate two colors. A path can have at most two weak links in a row, including where two groups join.

**Apply edits** applies the deductions and removes the chains that supplied them. Press **F** to apply those edits. If a revealed hint shows **Apply hint**, **F** applies the hint first. Puzzle **Undo** restores chains removed by edits such as placing a digit.

Linked candidates marked for removal have a faded chain bubble and digit with a thin black strike-through. Other candidates marked for removal have a red strike-through. If a color would leave a cell without candidates, Chains highlights that cell in red.
