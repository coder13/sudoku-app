| Source | When to use it |

| [Board](../../../../src/components/Board.tsx) | `Board` renders a Sudoku grid with givens, entries, candidates, selection, and optional teaching annotations. Use `highlightCandidateCells` to fill cells that match a digit or contain a possible link target. Highlighted candidates use circles in grid slots and rounded squares for center marks, with an opaque fill over selected cells. The `emphasized` candidate mark uses a solid fill and contrasting text for connected candidates in Chains. Set `strike` on an emphasized candidate to fade its chain bubble and add a black slash. Use the `strike` mark for an elimination without a chain bubble. Pass a sized layout for a 4×4 or 6×6 grid. Its box dimensions also determine the candidate slot layout. It reserves cell-sized outside-clue gutters independently of coordinate guides, keeping grid and link coordinates aligned. Outside clues expand teaching crops to the full grid so the entire constrained row or column remains visible. An overlay can replace the grid visually while preserving its dimensions. |
| [OutsideClues](../../../../src/components/OutsideClues.tsx) | `OutsideClues` draws Sandwich/X-Sums totals, Skyscrapers visibility counts and Little Killer arrows in the same inner-cell viewport as candidate links, including the grid border inset. It reserves edge and corner gutters, keeps zero Sandwich totals visible, and moves repeated anchors outward along their actual rays. When orthogonal families mix, numbers have S/X/Sk prefixes with a visible legend in Board. Its accessible description names each clue's rule, direction and covered cells. |
| [BoardAnnotations](../../../../src/components/BoardAnnotations.tsx) | `BoardLinks` draws supplied links between grid positions for chains and teaching diagrams. Pass the grid’s candidate insets when Clone labels or cage totals shift candidate positions. Set `colorBreak` on the link where the chain colors repeat in an odd loop. | [VariantClues](../../../../src/components/VariantClues.tsx) | `VariantClues` renders the visible rules for a variant grid. `Cage` outlines the cells of a cage and leaves space for its caption. `AlgebraicCages` places these outlines on a 4×4 grid. `SixClues` places rules on a 6×6 grid. `DiagonalClue`, `ParityClue`, `ThermometerClue`, and `RenbanClue` use the same clue shapes on both grid sizes. `RenbanClue` draws each authored segment of the consecutive set. The grid renderer places authored expressions in their cells and includes them in cell descriptions. `ExtraRegion` marks additional regions. `CloneClue` shades every cell in a Clone clue; letters identify transitive matching sets, including disconnected or overlapping copies. Candidate grids reserve space below the digits for these labels. `ArrowClue` draws a bulb and arrow. `RegionSumClue` draws blue paths with independent line colors, preserving closed geometry and separated logical nodes. `BetweenClue` draws a line with two endpoint circles. Dotted cells and dashed connectors identify separated logical cells; interior digits can repeat. `InequalityClue` marks a comparison. `ColoredLineLane` routes colored rule lines. `WhispersLabel` labels a Whispers line. `SumClue` places a sum indicator. Use its optional `viewBox` to crop a clue example; full-grid callers keep the default 9×9 view. |
| [Controls](../../../../src/components/Controls.tsx) | `Controls` provides the solving keypad and tool actions. Supply `toggleColorMode` for a keypad that offers a direct Color mode toggle. The desktop Play workspace opens Colors from Puzzle options. When multiple digits are highlighted, All or Any appears in a reserved space beside Highlight on desktop and mobile. Standard Play and mobile show Multi-select. P and Q cycle Pen, Pencil, and Highlight. The separate Highlight control temporarily supersedes the saved Pen or Pencil choice. Click a given in Highlight mode to toggle its digit. In Pen or Pencil, choosing a digit after selecting a given clears the cell selection and changes the highlight. Advanced desktop uses its Multi-select button setting. Pass the grid size for a 4×4 or 6×6 keypad and its completion indicators. Keypad progress can dim completed digits or show the remaining count. Pen, Pencil, and Highlight use Shift+digit to match any highlighted digit. Cmd/Ctrl+digit toggles candidates in selected cells or matches all highlighted digits with no cells selected. |
| [PuzzleKeypad](../../../../src/components/PuzzleKeypad.tsx) | `PuzzleKeypad` displays the digit pad, cell choices, or color palette. Pass the mini or six layout for four or six Sudoku digits. Use the choices layout for decisions such as Keep and Remove. Callers supply key labels, actions, and disabled states. |
| [CellColorPalette](../../../../src/components/CellColorPalette.tsx) | `CellColorPalette` combines color target and swatches. `ColorTargetPicker` chooses cells or candidates. `ColorSwatches` lets the player select a brush. |
| [ChainsPanel](../../../../src/components/ChainsPanel.tsx) | `ChainsPanel` manages player-drawn chains saved with the puzzle. The Chains tab starts drawing strong and weak links, branches, and loops. The Hide control is available once a chain has a link. The Draw links shortcut opens the panel and starts drawing, or stops an active drawing session. In Standard desktop, its main actions share one row when space permits. Apply edits and Show strong links align to the right. Apply edits removes the chains that supplied deductions. The Apply edits shortcut uses the same action and gives precedence to a fully revealed hint. Puzzle Undo restores the edits and chains. Select an active branch tip again to remove its only link. Connecting two chains keeps the earlier chain number and its colors. Undo edit restores the previous chains. While drawing, it also restores the endpoint for the next link. The panel identifies techniques from the sketch. If a color would leave a cell without candidates, the grid highlights the cell named in the proof. Strong links alternate two candidate colors when possible. Each connected drawing uses one pair, including when weak links join its branches. Disconnected groups cycle through five color pairs in drawings and in Show strong links. Weak links and candidates without a strong-link color are gray. Manual drawing fills the cells that match the selected digit and distinguishes possible link targets within their highlighted cells. Drawing stops a third consecutive weak link, including when paths join. Selecting a candidate or line adds its connected links to the active chain and keeps the overlay visible while drawing. Digit keys and keypad taps switch to a single digit. Holding a digit on the mobile keypad or pressing Shift+digit toggles one digit at a time. An unfinished path and drawing mode stay available after a reload in the same tab. `LinkLegend` explains solid strong links and dashed weak links. `ChainSwatches` displays a sketch’s two colors. `ChainResults` groups deductions by technique. `ChainActionsMenu` holds optional actions for the active sketch, including Choose colors. `ChainColorsDialog` chooses a pair for the active sketch and links to the Chain colors settings. |
| [SubsetsPanel](../../../../src/components/SubsetsPanel.tsx) | `SubsetsPanel` compares the candidates in the selected cells. When the selection forms a naked subset, the panel counts the candidates that the grid marks for removal. |
| [ActionHistoryPanel](../../../../src/components/ActionHistoryPanel.tsx) | `ActionHistoryPanel` shows a puzzle’s recorded moves and provides navigation through them. Pass the grid size for sized-puzzle coordinates. |

| [PuzzleAnalysis](../../../../src/components/PuzzleAnalysis.tsx) | `PuzzleAnalysis` owns the analysis interaction. `PuzzleAnalysisCard` wraps the analysis in a standalone card. `PuzzleAnalysisContents` embeds the report in an existing surface. `AnalysisTable` lays out the report’s technique counts. Its category rows use compact, even vertical padding. `PlacementAnalysis` uses the same table for placements or choices from number puzzle engines. The private `SizedAnalysis` requests the techniques for a 4×4 or 6×6 grid in one operation. The private `StandardAnalysis` scans the existing 9×9 techniques individually. |
| [PuzzleCheckResult](../../../../src/components/PuzzleCheckResult.tsx) | `PuzzleCheckResult` displays the outcome of an explicit puzzle check. |
| [SolutionPath](../../../../src/components/SolutionPath.tsx) | `SolutionPath` embeds a list of solving steps from Sudoku or a number puzzle engine. In tab panels, each step's title and explanation appear in its list row. `SolutionDialog` presents the path in a modal. A stalled path announces **Partial solution** before its steps, including a zero-step result. The mobile dialog uses the same title. The list and preview label a stalled endpoint **Last position** and a completed path **Final grid**. Use the partial, zero-step, complete, loading and unavailable [stories](../../../../stories/medium/SolutionPath.stories.tsx) to review these states. Pass the grid size for sized-puzzle coordinates. |
| [Worktable](../../../../src/components/Worktable.tsx) | `Worktable` coordinates interactions, solving tools, and state for a playable puzzle. View grid opens a temporary copy after a solve and keeps the saved result and elapsed time. Space pauses or resumes a puzzle and switches between the grid and results after a solve. One visible tab advances the timer for a puzzle. The elapsed time sits before the sync indicators so it stays in place as their status changes. The card shows when another device has the puzzle open and offers Catch up when the player can open that device’s latest puzzle. Its menu owns manual sync, in-progress status, and sync warnings. Mobile and desktop share the open tool panels and selected tab. In Puzzle options, desktop tab toggles include Solution, Techniques, Colors, Chains, and Subsets.
