## Puzzle input and tools

| Source | When to use it |
| --- | --- |
| [Board](../../../../src/components/Board.tsx) | `Board` renders a Sudoku grid with givens, entries, candidates, selection, and optional teaching annotations. Candidate highlights share the font color and shape setting. Pass a sized layout for a 4×4 or 6×6 grid. Its box dimensions also determine the candidate slot layout. It reserves cell-sized outside-clue gutters independently of coordinate guides, keeping grid and link coordinates aligned. Outside clues expand teaching crops to the full grid so the entire constrained row or column remains visible. An overlay can replace the grid visually while preserving its dimensions. |
| [OutsideClues](../../../../src/components/OutsideClues.tsx) | `OutsideClues` draws Sandwich/X-Sums totals, Skyscrapers visibility counts and Little Killer arrows in the same inner-cell viewport as candidate links, including the grid border inset. It reserves edge and corner gutters, keeps zero Sandwich totals visible, and moves repeated anchors outward along their actual rays. When orthogonal families mix, numbers have S/X/Sk prefixes with a visible legend in Board. Its accessible description names each clue's rule, direction and covered cells. |
| [BoardAnnotations](../../../../src/components/BoardAnnotations.tsx) | `BoardLinks` draws supplied links between grid positions for chains and teaching diagrams. Pass the grid’s candidate insets when Clone labels or cage totals shift candidate positions. Set `colorBreak` on the link where the chain colors repeat in an odd loop. |
| [BoardMarks](../../../../src/components/BoardMarks.tsx) | `BoardMarks` manages the appearance and removal of marks in a grid overlay. |
| [VariantClues](../../../../src/components/VariantClues.tsx) | `VariantClues` renders the visible rules for a variant grid. `Cage` outlines the cells of a cage and leaves space for its caption. `AlgebraicCages` places these outlines on a 4×4 grid. `SixClues` places rules on a 6×6 grid. `DiagonalClue`, `ParityClue`, `ThermometerClue`, and `RenbanClue` use the same clue shapes on both grid sizes. `RenbanClue` draws each authored segment of the consecutive set. The grid renderer places authored expressions in their cells and includes them in cell descriptions. `ExtraRegion` marks additional regions. `CloneClue` shades every cell in a Clone clue; letters identify transitive matching sets, including disconnected or overlapping copies. Candidate grids reserve space below the digits for these labels. `ArrowClue` draws a bulb and arrow. `RegionSumClue` draws blue paths with independent line colors, preserving closed geometry and separated logical nodes. `BetweenClue` draws a line with two endpoint circles. Dotted cells and dashed connectors identify separated logical cells; interior digits can repeat. `InequalityClue` marks a comparison. `ColoredLineLane` routes colored rule lines. `WhispersLabel` labels a Whispers line. `SumClue` places a sum indicator. Use its optional `viewBox` to crop a clue example; full-grid callers keep the default 9×9 view. |
| [Controls](../../../../src/components/Controls.tsx) | `Controls` provides the solving keypad and tool actions. On desktop, pass `onOpenColorTools` to open Colors and Chains from the palette button on a 9×9 grid. In compact Highlight mode, All or Any appears beside Highlight and uses a reserved space. Pass the grid size for a 4×4 or 6×6 keypad and its completion indicators. Keypad progress can dim completed digits or show the remaining count. |
| [PuzzleKeypad](../../../../src/components/PuzzleKeypad.tsx) | `PuzzleKeypad` displays the digit pad, cell choices, or color palette. Pass the mini or six layout for four or six Sudoku digits. Use the choices layout for decisions such as Keep and Remove. Callers supply key labels, actions, and disabled states. |
| [CellColorPalette](../../../../src/components/CellColorPalette.tsx) | `CellColorPalette` combines color target and swatches. `ColorTargetPicker` chooses cells or candidates. `ColorSwatches` lets the player select a brush. |
| [ChainsPanel](../../../../src/components/ChainsPanel.tsx) | `ChainsPanel` manages player-drawn chains saved with the puzzle. The Chains tab starts drawing strong and weak links, branches, and loops. Apply edits removes the chains that supplied deductions. Puzzle Undo restores the edits and chains. Select an active branch tip again to remove its only link. Undo edit restores that link. The panel identifies techniques from the sketch. Show strong links draws links between candidates highlighted with the shared keypad or grid. An unfinished path and drawing mode stay available after a reload in the same tab. `LinkLegend` explains solid strong links and dashed weak links. `ChainSwatches` displays a sketch’s two colors. `ChainResults` groups deductions by technique. `ChainActionsMenu` holds optional actions for the active sketch. |
| [SubsetsPanel](../../../../src/components/SubsetsPanel.tsx) | `SubsetsPanel` compares the candidates in the selected cells. When the selection forms a naked subset, the panel counts the candidates that the grid marks for removal. |
| [ActionHistoryPanel](../../../../src/components/ActionHistoryPanel.tsx) | `ActionHistoryPanel` shows a puzzle’s recorded moves and provides navigation through them. Pass the grid size for sized-puzzle coordinates. |
| [HintCard](../../../../src/components/HintCard.tsx) | `HintCard` presents the next hint in stages. Use the detail slot for a game-specific explanation. `DeductionExplanation` renders the reasoning for a deduction. `DeductionOutcome` summarizes the resulting placement or elimination. |
| [PuzzleAnalysis](../../../../src/components/PuzzleAnalysis.tsx) | `PuzzleAnalysis` owns the analysis interaction. `PuzzleAnalysisCard` wraps the analysis in a standalone card. `PuzzleAnalysisContents` embeds the report in an existing surface. `AnalysisTable` lays out the report’s technique counts. `PlacementAnalysis` uses the same table for placements or choices from number puzzle engines. The private `SizedAnalysis` requests the techniques for a 4×4 or 6×6 grid in one operation. The private `StandardAnalysis` scans the existing 9×9 techniques individually. |
| [PuzzleCheckResult](../../../../src/components/PuzzleCheckResult.tsx) | `PuzzleCheckResult` displays the outcome of an explicit puzzle check. |
| [SolutionPath](../../../../src/components/SolutionPath.tsx) | `SolutionPath` embeds a list of solving steps from Sudoku or a number puzzle engine. `SolutionDialog` presents that path in a modal. The list and preview label a stalled path **Last position** and a completed path **Final grid**. Pass the grid size for sized-puzzle coordinates. |
| [Worktable](../../../../src/components/Worktable.tsx) | `Worktable` coordinates interactions, solving tools, and state for a playable puzzle. View grid opens a temporary copy after a solve and keeps the saved result and elapsed time. Space pauses or resumes a puzzle and switches between the grid and results after a solve. The card shows when another device has the puzzle open and offers Catch up when the player can open that device’s latest puzzle. Its menu owns manual sync, in-progress status, and sync warnings. Puzzle options has separate toggles for Chains, Subsets, and Colors. The menu stays open after each toggle. |
| [CompletedPuzzle](../../../../src/components/CompletedPuzzle.tsx) | `CompletedPuzzle` shows solve results and offers to catch up to another device’s puzzle or resume the next playable attempt in last-played order. Pass `onResumePuzzle` to open the existing attempt by ID. New puzzle opens the variant and difficulty picker. When a collection can continue, its next puzzle is the primary action. The mobile worktable displays these actions in the keypad slot. Pure Whispers puzzles retain their German/Dutch ruleset for next-puzzle generation. |
