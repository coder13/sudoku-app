## Between Lines

The existing engine compiles ordered paths of at least three distinct cells. Every interior digit lies strictly between the two endpoint digits; interior digits can repeat when their houses and other rules permit it. Each original Coach `betweenLine` segment compiles independently. App rule acceptance, Coach decoding, grid markings, cell descriptions, placement cleanup and complete help/storage flows are now implemented, reusing existing native proofs and Learn content. [Source, behavior, generation and performance audit](SUDOKU_BETWEEN_AUDIT.md)

The first source controls are Philip Newman's [Between, the Lines](https://www.gmpuzzles.com/blog/2026/08/between-lines-sudoku-by-philip-newman/), with its published grid and solution PDFs, and Raumplaner's complete [Between the Dots](https://sudoku.coach/en/s/9KxH), which combines twelve Between paths and eleven black dots with zero givens. Keep every companion clue. The source fixtures retain original links, givens, ordered paths, printed completions and the original Coach code. Independent numeric search verifies one solution for both complete sources, matching the printed completions. The Newman control closes in one independent search node; the mixed Coach control uses 201. Static clue renders, actual app contracts and all exact-head release gates pass. The integration is on main at `30bbd85`.

## New Puzzle and import

The local New Puzzle chooser offers five built-in modes, Classic, X Sudoku, Windoku, Killer and Jigsaw, with four slots for pinned custom modes. The builder offers 35 rule choices, including separate diagonals, Kropki colors, V/X marks and Dutch Whispers. A named mode saves the rule choices and independent negative settings for white dots, black dots, V marks and X marks on the current device. A negative setting applies where neither mark from its family appears. Each new puzzle derives clues from a compatible solved grid, verifies uniqueness, and checks the selected rating. Custom modes offer Easy, Medium and Hard, with Tricky as the third grade for Jigsaw alone. The difficulty screen for a saved mode links to its editor. Players can cancel generation from the builder, saved mode or next-puzzle screen. A ten-second search deadline ends the worker if a combination exhausts its budget. All named 9×9 families remain available through the builder, and existing direct variant links continue to work.

The core chooser stays at 9×9. Generate a custom puzzle has a Grid selector for the existing smaller-grid generators and their box layouts. Its rule choices configure random generation. Players author grids and place variant clues in external editors, then bring the puzzle into the app through Import. In-app board authoring is outside the planned scope. Existing drafts can still be saved.
